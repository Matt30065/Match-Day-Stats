# Grassroots Match Tracker v20.6


v20.6 adds robust Result Card image sharing. Share now creates a PNG of the result card content (without navigation/action buttons). On browsers that support image file sharing, the native share sheet receives the PNG. If direct image sharing is unavailable, the PNG is saved so it can be shared from Photos/Gallery instead of silently falling back to text.

The existing fluid first-use onboarding, match lobby, batch substitutions, scorer grouping, half-aware goal times and `(Pen)` notation are retained.
